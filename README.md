# ISP Management System

This project is a comprehensive ISP Management System built with React, Node.js, and MongoDB. It provides features for managing PPPoE users, resellers, subscriptions, invoices, network monitoring, and more.

## Features

- User Management (PPPoE Users, Resellers, Admins)
- Subscription and Package Management
- Invoice Generation and Management
- Network Monitoring and Topology Visualization
- Bandwidth Usage Tracking
- Support Ticket System
- Reporting and Analytics
- Real-time Notifications
- WhatsApp and SMS Integration

## Tech Stack

- Frontend: React, TypeScript, Tailwind CSS, shadcn/ui
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JSON Web Tokens (JWT)
- Real-time Updates: Socket.IO

## Prerequisites

- Node.js (v14 or later)
- MongoDB
- Redis
